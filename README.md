# spot-agent

StudySpot은 서울의 API 지원 상권을 대상으로 스터디카페 창업 조건에 맞는 후보를 비교하는 AI Agent 프로젝트다.

## 설계 문서

- [전체 구조도와 모듈 담당](docs/architecture.md)
- [동작 흐름과 분기](docs/flow.md)
- [모듈 연결 규격과 합의할 사항](docs/interfaces.md)

설계서는 `8반_1조_설계서(초안).docx`와 팀의 폴더 구성을 기준으로 정리했다. 원문 요구사항, 연결 제안, 합의가 필요한 항목을 문서에서 구분한다. 구조도와 흐름도는 Mermaid 형식이며 GitHub 등 Mermaid를 지원하는 Markdown 뷰어에서 볼 수 있다.
